# Landing Page Videos (Match)

Place your video files in this `public/videos` directory. Based on the Match component code, the landing page expects the following exact video filenames to be present to work correctly:

1. `banner.mp4`: The main hero background video (`Home/Banner.tsx`).
2. `featured-video.mp4`: Used in the featured project preview and the 'Find Projects' menu hover state.
3. `easy.mp4`: Used for the 'Find Teammates' menu hover state.
4. `make-it-zero.mp4`: Used for the 'How it Works' menu hover state.
5. `it-takes-an-island.mp4`: Used for the 'Sign In' menu hover state.
6. `50-beaches.mp4`: Used for the 'Get Started' (Signup) menu hover state.

Ensure your files are named exactly as shown above (case-sensitive) and are in `.mp4` format. Next.js will automatically serve them from this folder at the `/videos/` path.
